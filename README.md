📰 NewsGrid Portal - Modern News & Blog Web App

CSS Grid ve Flexbox düzenleri odaklı geliştirilmiş; teknoloji, ekonomi, kültür, spor ve sağlık kategorilerinde makaleler barındıran responsive haber/blog portalı uygulaması.

---

## 📌 Proje Özellikleri

- **Kapsamlı İçerik & Sayfa Yapısı:** 
  - Ana portal sayfası (`index.html`)
  - Hakkımızda/Künye sayfası (`about.html`)
  - 6 farklı kategori için özel makale detay sayfaları (Teknoloji, Spor, Ekonomi, Kültür, Sağlık, Bilim)[cite: 14]
- **CSS Grid Mimarisi:** Kart yerleşimleri ve ana haber düzeni için gelişmiş CSS Grid kullanımı.
- **Responsive & Mobil Uyumlu:** Farklı ekran çözünürlüklerine uyum sağlayan esnek medya sorguları (Media Queries).

---

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Semantik etiket yapısı ve modüler sayfa bağlantıları.
- **CSS3:** CSS Grid, Flexbox mimarisi ve custom responsive tasarımlar.
